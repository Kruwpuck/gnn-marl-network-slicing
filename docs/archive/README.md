# Archive

Documents that are no longer current but are kept on purpose.

None of these describes the repository as it stands. They are here because the paper's
methodology section needs the trail of what was believed at each stage, and because
deleting a superseded document destroys the evidence that a claim was later revised.
Nothing in the repo links to them for a live fact.

| File | Written for | Superseded by |
|---|---|---|
| `HANDOFF.md` | env v2 "coupled interference", pre-v3 | `docs/HANDOVER.md` |
| `RENCANA_PENELITIAN.md` | the pre-v3 research plan | `handoff/goal1.md` (done criteria), `handoff/paper_structure.md` (claims) |
| `TRAINING_STATUS.md` | v3 training progress | `results/*.md`, `STATE.json` |

**Line numbers inside these files are not maintained.** A citation such as
`envs/network_slicing_env.py:174` was correct when written and is not re-pointed at
today's code -- doing so would make an old document appear to describe current
behaviour. `scripts/citation_audit.py` skips this directory for that reason.

Moved here from the repository root on 2026-08-23. Each had zero inbound references at
the time of the move.
